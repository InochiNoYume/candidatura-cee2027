# Fotografías individuales de integrantes

Carpeta reservada para retratos individuales de integrantes de la lista o directiva, únicamente cuando se entreguen fotografías reales y exista autorización para publicarlas.

**Estado actual:** pendiente de recibir fotografías autorizadas. No crear retratos ficticios ni utilizar imágenes de otras personas.

## Convención de nombres

Usa el cargo para mantener una estructura estable, sin necesidad de incluir nombres personales en las rutas:

- `presidencia.jpg`
- `vicepresidencia.jpg`
- `secretaria-ejecutiva.jpg`
- `voceria.jpg`
- `tesoreria.jpg`
- `secretaria-actas.jpg`
- `vocalia-deportes.jpg`
- `vocalia-tecnico-profesional.jpg`

Si se necesita más de una toma, agrega un sufijo: `presidencia-02.jpg`.

## Reglas

- Minúsculas, sin tildes, espacios ni caracteres especiales; separar palabras con guiones.
- Extensiones permitidas: `.jpg`, `.jpeg`, `.png` o `.webp`; conserva la extensión real.
- Evita incluir nombres completos u otros datos personales en los nombres de archivo.
- Antes de incorporar una fotografía, confirma la autorización para publicarla en la web.
