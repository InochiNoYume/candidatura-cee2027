# Fotografías individuales de integrantes

Guarda aquí retratos individuales de integrantes de la lista o directiva, siempre que estén autorizados para publicarse.

## Nombres de archivo

Usa el cargo, no el nombre de la persona, para mantener una estructura estable:

- `presidencia.jpg`
- `vicepresidencia.jpg`
- `secretaria-ejecutiva.jpg`
- `voceria.jpg`
- `tesoreria.jpg`
- `secretaria-actas.jpg`
- `vocalia-deportes.jpg`
- `vocalia-tecnico-profesional.jpg`

Si se necesita más de una toma, agrega un sufijo: `presidencia-02.jpg`.

## Reglas
- Minúsculas, sin tildes, espacios ni caracteres especiales; separar palabras con guiones.
- Extensiones permitidas: `.jpg`, `.jpeg`, `.png` o `.webp`; conserva la extensión real.
- No inventes retratos ni uses imágenes de otras personas como reemplazo.
- Antes de incorporar una fotografía, confirma la autorización para publicarla en la web.
