# Imágenes de Comunidad Técnico-Profesional

Carpeta opcional para fotografías y recursos visuales de proyectos, especialidades, muestras técnicas y experiencias de aprendizaje TP.

## Convención de nombres

- `proyectos-tp-nombre-del-proyecto-01.webp`
- `especialidad-nombre-de-la-especialidad-01.webp`
- `muestra-tecnica-AAAA-MM-01.webp`
- `conversatorio-exalumnos-AAAA-MM-01.webp`

Los nombres son ejemplos de formato; no representan actividades ya realizadas.

## Cuándo se necesita

- **Opcional:** la página puede funcionar sin fotografías mientras el espacio esté por desarrollar.
- Agrega imágenes solo cuando existan proyectos o experiencias reales que se puedan documentar.
- Comprueba que la fotografía corresponda a la especialidad o actividad descrita.
- Solicita autorización antes de publicar estudiantes, trabajos identificables o material de terceros.

Prefiere WebP optimizado o JPG/JPEG y conserva la extensión real. Si no existe una imagen adecuada, deja la sección sin imagen en vez de usar una fotografía genérica.
