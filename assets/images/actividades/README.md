# Fotografías de actividades

Carpeta reservada para fotografías reales de actividades del CEE/CEAT: reuniones, jornadas, campañas, encuentros y eventos.

**Estado actual:** no incorporar fotografías hasta que se entreguen recursos reales y exista autorización para su publicación.

## Convención de nombres

Usa `AAAA-MM-DD-nombre-de-la-actividad-01.webp`.

Ejemplos de formato (no son actividades confirmadas):
- `2027-03-15-jornada-bienvenida-01.webp`
- `2027-04-08-campana-reciclaje-01.jpg`

## Reglas

- Fecha primero en formato `AAAA-MM-DD`; si no se conoce el día, usa `AAAA-MM`.
- Minúsculas, sin tildes, espacios ni caracteres especiales; separa palabras con guiones.
- Numera las tomas de una misma actividad con dos dígitos: `01`, `02`, `03`.
- Extensiones permitidas: `.jpg`, `.jpeg`, `.png` o `.webp`; conserva la extensión real.
- No agregues imágenes ficticias ni fotografías que hagan parecer que una actividad ya ocurrió.
- Publica imágenes de estudiantes solo cuando exista autorización para su difusión.
