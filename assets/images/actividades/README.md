# Fotografías de actividades

Guarda aquí fotografías reales de actividades del CEE/CEAT: reuniones, jornadas, campañas, encuentros y eventos.

## Formato del nombre

Usa: `AAAA-MM-DD-nombre-de-la-actividad-01.jpg`

Ejemplos:
- `2027-03-15-jornada-bienvenida-01.jpg`
- `2027-04-08-campana-reciclaje-01.webp`
- `2027-05-20-torneo-deportivo-02.jpg`

## Reglas
- Fecha primero en formato `AAAA-MM-DD`; si no se conoce el día, usa `AAAA-MM`.
- Escribe en minúsculas, sin tildes, espacios ni caracteres especiales; separa palabras con guiones.
- Numera las fotos de una misma actividad con dos dígitos: `01`, `02`, `03`.
- Extensiones permitidas: `.jpg`, `.jpeg`, `.png` o `.webp`. Conserva la extensión real del archivo.
- No agregues imágenes de ejemplo ni fotografías que hagan parecer que una actividad ya ocurrió.
- Publica imágenes de estudiantes solo cuando exista autorización para su difusión.
