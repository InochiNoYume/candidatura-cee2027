# Imágenes para noticias

Carpeta opcional para imágenes de portada o apoyo de noticias y comunicados.

## Convención de nombres

Usa una fecha y un título corto:

- `AAAA-MM-DD-titulo-noticia.webp`
- Si una noticia necesita más de una imagen: `AAAA-MM-DD-titulo-noticia-02.webp`

Ejemplo de formato: `2027-03-15-jornada-bienvenida.webp` (nombre ilustrativo, no confirma que esa actividad haya ocurrido).

## Cuándo se necesita

- **Opcional:** no todas las noticias necesitan imagen.
- Usa fotografías reales solo cuando documenten el contenido de la noticia y exista autorización.
- Si no hay una imagen pertinente, la noticia debe mostrarse correctamente sin imagen.

Prefiere WebP optimizado o JPG/JPEG. Conserva la extensión auténtica y no uses imágenes de relleno que puedan inducir a error.
