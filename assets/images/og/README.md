# Imágenes para compartir enlaces

Esta carpeta contiene recursos gráficos usados en las vistas previas al compartir la web en redes sociales y mensajería.

## Nombre actual

- `cee-2027-social.svg` — imagen de vista previa general del sitio.

## Para nuevas versiones

Usa el patrón `cee-2027-social-variante.svg`, por ejemplo `cee-2027-social-oscura.svg`.

Mantén nombres en minúsculas, sin tildes ni espacios. Si cambias el nombre de un archivo existente, actualiza también las etiquetas Open Graph y Twitter Card de las páginas.
