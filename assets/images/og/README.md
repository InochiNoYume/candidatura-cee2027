# Recursos Open Graph y redes sociales

Esta carpeta contiene imágenes utilizadas en las vistas previas al compartir páginas en redes sociales y aplicaciones de mensajería.

## Recurso actual

- `cee-2027-social.svg`: imagen de vista previa general del sitio (1200 × 630 según los metadatos de las páginas).

## Para nuevas versiones

Usa el patrón `cee-2027-social-variante.svg`, por ejemplo `cee-2027-social-oscura.svg`.

## Reglas

- Mantén una composición legible en formato horizontal 1.91:1.
- Usa nombres en minúsculas, sin tildes ni espacios.
- Si cambias un recurso, actualiza las etiquetas Open Graph y Twitter Card de las páginas correspondientes.
- Comprueba la vista previa en fondo claro y oscuro y evita texto demasiado pequeño.
