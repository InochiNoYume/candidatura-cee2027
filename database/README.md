# Base de datos CMS

`schema.sql` contiene el esquema inicial propuesto para Cloudflare D1 (SQLite). No se ha aplicado ni desplegado.

Antes de crear D1: revisar nombres y relaciones, decidir retención de versiones/auditoría, plan de backup y variables de entorno. Usar una instancia nueva dedicada al CMS; no reutilizar una base existente sin aprobación.
