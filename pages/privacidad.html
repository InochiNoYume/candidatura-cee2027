Uso responsable de la información

Privacidad y participación.

Información sobre el propósito de los canales de participación y el tratamiento responsable de los mensajes recibidos.

¿Para qué recibimos opiniones?

CEAT Te Escucha busca recoger ideas, sugerencias e inquietudes para conocer las necesidades del estudiantado y orientar el trabajo de representación.

Uso de la información

Los mensajes se utilizarán para revisar temas de interés estudiantil, identificar propuestas y, cuando corresponda, coordinar respuestas o gestiones. No se deben compartir datos sensibles ni información privada de otras personas.

Publicación y confidencialidad

No se publicarán nombres, datos de contacto ni el contenido identificable de una respuesta sin autorización. Los temas podrán resumirse de forma general para informar tendencias o avances, evitando exponer a quienes participaron.

Formulario externo

El formulario oficial de Google se enlazará cuando esté configurado y revisado. Antes de enviarlo, se indicará qué datos solicita y quién tendrá acceso a las respuestas.

Asistente de ayuda con inteligencia artificial

Si utilizas el asistente, el texto de tu pregunta se envía desde el servidor del sitio a Google Gemini API. La función selecciona páginas públicas de esta web según el tema de la consulta y utiliza la herramienta de contexto de URL de Gemini para recuperar su contenido. Gemini utiliza el contenido de las páginas públicas seleccionadas para fundamentar sus respuestas. La interfaz no muestra un apartado de fuentes consultadas ni enlaces de fuentes debajo de cada respuesta. No se utiliza la búsqueda general de Google para responder sobre la candidatura. No escribas nombres, teléfonos, direcciones, datos académicos privados ni datos personales tuyos o de otras personas.

El sitio no guarda un historial de conversaciones ni almacena las preguntas en una base de datos propia. La función utiliza temporalmente la dirección IP que entrega Cloudflare para aplicar un límite básico de consultas por instancia. El contenido de las páginas públicas seleccionadas y el texto de la pregunta se procesan mediante Gemini API. En el nivel gratuito de Gemini API, Google puede utilizar los datos enviados para mejorar sus productos y los datos pueden ser revisados por personas. Consulta las condiciones de uso de Gemini API y la política de privacidad de Google.

Esta página describe el criterio de participación previsto para el proyecto. Se actualizará con los detalles del formulario cuando el enlace y sus ajustes de privacidad estén definidos.
